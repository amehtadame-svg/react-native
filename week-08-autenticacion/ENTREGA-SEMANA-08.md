# Entrega Semana 08 — Autenticación

Dominio: **fundaciones/ONG**.

## Completado

- Práctica 01: login JWT contra DummyJSON, decodificación del JWT, almacenamiento seguro en SecureStore, llamada autenticada a `/auth/me` y logout.
- Práctica 02: OAuth 2.0 con PKCE mediante Expo AuthSession, redirect URI, discovery de GitHub y recepción del authorization code.
- Proyecto: auth store con Zustand, tokens en SecureStore, login, registro simulado, refresh de tokens y navegación condicionada por autenticación.
- Login con React Hook Form y Zod, mensajes de error y acceso demo `emilys` / `emilyspass`.

## Ejecución

```bash
cd 3-proyecto/starter
pnpm install
pnpm start
```

Para OAuth reemplaza el client ID de GitHub y configura el scheme de la app.

# Entrega Semana 05 — Networking y TanStack Query

Dominio: **fundaciones/ONG**.

## Completado

- Práctica 01: `QueryClientProvider`, `useQuery`, Axios, estados de carga/error y pull-to-refresh.
- Práctica 02: `useMutation` para crear y eliminar registros, invalidación de caché y estados de mutación.
- Proyecto: catálogo de fundaciones consumiendo JSONPlaceholder como API pública de práctica, mapeo de datos al dominio ONG, reintento y refresco.
- Hooks separados para listar, consultar por ID, crear y eliminar.

## Ejecución

```bash
cd 3-proyecto/starter
npm install
npx expo start
```

Se requiere conexión a internet para consultar JSONPlaceholder.

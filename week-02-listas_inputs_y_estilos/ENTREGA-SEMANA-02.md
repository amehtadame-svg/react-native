# Entrega Semana 02 — Listas, Inputs y Estilos

Dominio: **fundaciones/ONG**.

## Completado

- Práctica 01: `FlatList` con 12 organizaciones, separadores, estados vacío, `Pressable` y pull-to-refresh.
- Práctica 02: búsqueda en tiempo real con `TextInput`, `useMemo`, `KeyboardAvoidingView`, estado vacío y 18 organizaciones.
- Proyecto: catálogo de fundaciones con `FlatList`, búsqueda por nombre, causa o ciudad, tarjetas estilizadas y tipado TypeScript.

## Ejecución

```bash
cd 3-proyecto/starter
pnpm install
pnpm start
```

También se pueden ejecutar los starters de cada práctica desde sus carpetas respectivas.

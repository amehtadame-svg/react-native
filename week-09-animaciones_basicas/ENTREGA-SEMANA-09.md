# Entrega Semana 09 — Animaciones básicas

Dominio: **fundaciones/ONG**.

## Completado

- Práctica 01: `Animated.timing`, `Animated.spring`, `Animated.parallel` y `Animated.sequence`.
- Práctica 02: `Animated.loop`, `interpolate` para rotación, ancho y color, y `Animated.stagger`.
- Proyecto: componentes `AnimatedCard` y `AnimatedButton` con feedback de escala, `ProgressBar` con interpolación de ancho/color y pantallas preparadas para animaciones de entrada y cambios de layout.
- Animaciones ejecutadas con `useNativeDriver` cuando la propiedad lo permite; `useNativeDriver: false` para ancho y color.

## Ejecución

```bash
cd 3-proyecto/starter
pnpm install
pnpm start
```
